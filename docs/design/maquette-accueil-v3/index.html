Questions fréquentes

L'audit est-il vraiment gratuit ?

Oui, sans compte et sans traceur. Vous obtenez la note et les priorités. Un compte gratuit ouvre le détail, le lien de partage et le prompt pour votre assistant IA.

Le rapport est-il écrit par une IA ?

Non. Les mesures et le rapport sont calculés par Audixio. Nous vous donnons seulement un prompt prêt à coller dans l'assistant IA de votre choix.

Comment la note est-elle calculée ?

Chaque domaine est noté sur 100 : A à partir de 90, B à partir de 80, C à partir de 65, D à partir de 50, E à partir de 35, F en dessous.

Audixio peut-il abîmer mon site ?

Non. L'analyse est passive par défaut : Audixio lit votre site comme un visiteur. Les tests actifs exigent une preuve de propriété revérifiée juste avant.
