Performance

Inclus sans compte

Votre page s’affiche-t-elle vite ?

Ce qu’on regarde

  • Le temps d’affichage du contenu principal
  • Le poids des images et des scripts
  • La stabilité de la page pendant le chargement

Pourquoi c’est important

Une page lente fait partir des visiteurs avant même qu’ils l’aient vue.

Exemple de constat : Image d’accueil de 2,4 Mo.

SEO

Inclus sans compte

Google comprend-il votre page ?

Ce qu’on regarde

  • Le titre et la description de la page
  • Le sitemap et le fichier robots.txt
  • La langue et l’adresse de référence

Pourquoi c’est important

C’est ce qui décide si l’on vous trouve dans une recherche.

Exemple de constat : Aucun titre principal.

Accessibilité

Inclus sans compte

Tout le monde peut-il lire et cliquer ?

Ce qu’on regarde

  • Le contraste entre le texte et le fond
  • Les boutons et les images nommés
  • La navigation au clavier

Pourquoi c’est important

Malvoyants, daltoniens, clavier seul : chacun doit pouvoir utiliser le site. Critères inspirés du RGAA.

Exemple de constat : Bouton d’envoi sans nom.

Écologie

Inclus sans compte

Votre page est-elle sobre ?

Ce qu’on regarde

  • Le volume de données transférées
  • Le nombre de requêtes
  • La complexité de la page

Pourquoi c’est important

Moins de données, c’est moins de forfait et de batterie consommés.

Exemple de constat : Images non compressées.

Qualité technique

Inclus sans compte

Le code est-il sain et à jour ?

Ce qu’on regarde

  • Les liens cassés
  • Les bibliothèques JavaScript obsolètes
  • Les failles connues déclarées publiquement

Pourquoi c’est important

Un site qui marche partout, sans clic qui mène nulle part.

Exemple de constat : Lien cassé dans le pied de page.

Questions

Avant de lancer un scan

Comment fonctionne AudixioLa méthode, le barème et les limites.
Une bonne note veut-elle dire que mon site est conforme ?

Non. La note mesure des critères automatiques, inspirés du RGAA pour l'accessibilité. Seul un audit humain peut établir une conformité.

Est-ce que le scan peut gêner mon site ?

Non. Le robot d'Audixio lit la page comme un visiteur, sans rien soumettre ni modifier.

Ce que visite notre robot
L'IA intervient-elle dans la note ?

Non. La note vient d'un barème fixe et public. Le même site, au même moment, donne le même résultat.
